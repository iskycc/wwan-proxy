# wwan-proxy 功能演进建议

以下仅列当前实现之上的剩余增量，不重复 README 已说明的现有能力。当前基线已经包含实例级目标 ACL、来源 CIDR admission、全局及每来源 IP 连接/UDP association 限制、DoH 正负缓存和多端点并发择优。排序综合考虑用户价值、代理稳定性和实现风险。

## P0：建议优先

### 1. 容量基准与保护

- 在目标硬件上建立 TCP 1k/5k/10k 长连接、短连接 CPS、UDP PPS 和混合流量基准。
- 展示文件描述符、连接建立失败率、丢包、socket buffer 和 conntrack 使用率。
- 在现有全局和每来源 IP 并发限制之上，增加每用户连接上限、带宽限速和突发保护。
- 根据压测结果评估 `SO_REUSEPORT`、buffer pool 和多 worker 模式。

价值：把“架构支持高并发”变成有具体容量边界的生产结论。

### 2. 配置版本与备份恢复

- 每次保存前自动创建配置修订，支持差异查看和一键回滚。
- WebUI 下载加密数据库备份、上传校验并恢复。
- 数据库迁移前后自动保留可识别的恢复点。

价值：降低错误配置和磁盘故障带来的恢复成本。

### 3. 告警通知

- 心跳失败、IP 变化、接口掉线、端口启动失败和资源超限时发送 Webhook。
- 可选邮件、Telegram、企业微信、钉钉或 Slack 通知。
- 支持连续失败阈值、恢复通知和告警抑制，避免抖动刷屏。

价值：无需持续盯着 WebUI 才能发现出口故障。

### 4. HTTPS 与更强认证

- 原生 TLS 或自动生成本地证书，并支持反向代理可信头配置。
- TOTP 二次认证、恢复码、登录历史和可选 Passkey。
- 多管理员与只读审计角色。

价值：远程管理时显著降低账号和 Cookie 被窃取的风险。

## P1：网络能力增强

### 5. Linux 出口池与自动故障转移

- 将多个接口组成出口组，支持主备、轮询、加权和最少连接策略。
- 心跳失败后停止分配新连接，恢复稳定后自动加入。
- 支持按用户名、来源网段或目标域名固定出口。

价值：从“一个端口固定一个接口”升级为可编排的多链路网关。

### 6. 网口与 Modem 详细状态

- 在现有 `/api/interfaces` 网口名称、地址、MTU 和 flags 发现能力之上，展示默认路由、实时收发包、丢包和错误计数。
- 对接 ModemManager/QMI/MBIM，展示运营商、SIM、信号强度、RSRP、RSRQ、SINR 和制式。
- 统计每接口日/月流量并设置套餐阈值。

价值：定位问题时能区分代理、路由、射频信号和运营商侧故障。

### 7. 用户级 ACL、配额和审计

- 在现有实例级域名、CIDR、端口目标 ACL 之上，增加按 SOCKS5/HTTP Proxy 用户和协议划分的规则。
- 每用户连接数、速率、日/月流量配额。
- 可选访问审计日志，并提供隐私脱敏和保留策略。

价值：适合多人或多业务共享同一出口。

### 8. DNS 可观测性与高级策略

- 为现有 DoH TTL 正/负缓存增加命中率、查询延迟、上游错误和淘汰指标；按需要评估传统 DNS 的进程内缓存。
- 在现有多 DoH 端点并发择优和单次请求故障容错之上，增加持续健康检查、熔断和恢复探测，避免长期故障端点持续参与每次竞速。
- 可选 DNSSEC 校验和域名规则分流。

价值：降低重复解析延迟，提升 DoH 服务异常时的可用性。

## P2：高级运维与协议

### 9. 可观测性集成

- Prometheus `/metrics`、OpenTelemetry traces 和结构化访问指标。
- 按实例、用户、协议和错误原因拆分吞吐与连接趋势。
- 支持导出诊断包，包含脱敏配置、关键日志和系统网络状态。

### 10. 在线诊断工具

- WebUI 一键执行出口 IP、DNS、DoH、TCP、UDP、MTU 和 IPv6 检测。
- 对比多个物理/虚拟出口网口的延迟、丢包和公网 IP。
- 自动检查 `SO_BINDTODEVICE` 权限、防火墙端口范围和文件描述符限制。

### 11. 协议完善

- SOCKS5 UDP FRAG 重组（当前按 RFC 1928 允许的策略直接丢弃非零 FRAG）。
- 更完整的 IPv6 双栈 relay 广播地址选择。
- 可选 TCP Fast Open、客户端 keepalive 策略和上游连接统计。

### 12. 高可用

- 多节点配置同步、主备 WebUI 和状态聚合。
- 节点级健康检查与 VIP/负载均衡器接入。
- 加密的集中式配置和审计记录。
